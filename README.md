## 🌟 代表项目：千面 Facet

**[千面 Facet](https://github.com/HEYD66/facet)** —— 以用户隐私保护为核心、内置 AI 助手的 Windows 开源多实例浏览器。

- **独立会话隔离**：每个实例独立保存 Cookie、网站存储、浏览器环境与代理网络，代理失败不自动切回直连
- **双栏内置 AI 助手**：官方 DeepSeek Harness 引擎，支持多会话独立并行、模型与推理强度选择、图片输入与 6 路并行工具调用
- **高效多开工作台**：实例分组与拖拽排序、单实例多网页标签、实时宫格同屏监控、节点端口共享与获取免费节点、`.facetbackup` 备份迁移
- **自动化友好**：支持本机回环控制 API 与统一 CDP 端口，便于 Playwright 及外部 AI 接手
